This is a proteus simulation of a robotic arm consisting of six servo motors, an arduino Uno and a power source. The motors are connected in parallel hence the same amount of voltage flows through them but the current divides. The control pin of each servo is connected to a different Pulse width modulation(PWM) pin on the arduino UNO to allow independent movement of the joints of the arm. I included the proteus file, a picture of the circuit and a video of a test simulation to check if every thing was connected properly.
